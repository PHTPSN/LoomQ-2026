02 · Quantum basics

Six ideas are enough
to read your first circuit.

Think like a programmer: a circuit is an ordered instruction list that transforms a state and then samples an answer.

01 / DATA

Qubit

A quantum bit. Before measurement, its state can contain weighted |0⟩ and |1⟩ components.

02 / STATE

Superposition

A combination of basis states. Squared amplitude magnitudes become measurement probabilities.

03 / CODE

Gate and circuit

A gate is one reversible transformation; a circuit is the ordered list of those instructions.

04 / OUTPUT

Measurement

Converts quantum information into classical bits such as 00 or 11.

05 / SAMPLE

Shots

How many times the circuit is prepared and measured. More shots make the histogram steadier.

06 / LINK

Entanglement

A shared state with correlated outcomes. A Bell pair returns matching bits even though each bit is random.

A two-gate story

How a Bell pair is made

Start with two zeroes. H creates two paths; CX links them. Measurement then returns mostly 00 or 11.

  1. START|00⟩Known input
  2. GATEh q[0]Two paths
  3. LINKcx q[0],q[1]Entangle
  4. MEASURE00 ≈ 11Correlated counts
One important convention

In result key “10”, the rightmost character is c[0]. LoomQ normalizes every backend to this little-endian convention.

03 · Official gate set

Twelve gates.
The complete vocabulary.

Hidden competition cases use this same whitelist. θ is a rotation angle measured in radians; “dg” means the inverse gate.

Single-qubitPhase and rotationControlled and multi-qubit
01h1 qubit

Hadamard

Creates or recombines equal quantum paths—the usual doorway into superposition.

h q[0];
02x1 qubit

Bit flip

Swaps |0⟩ and |1⟩. It is the quantum counterpart of classical NOT.

x q[0];
03s1 qubit

Quarter phase

Adds a 90° phase to |1⟩. Interference makes that hidden phase observable.

s q[0];
04sdg1 qubit

Inverse S

Applies the opposite −90° phase. “Dagger” means inverse.

sdg q[0];
05t1 qubit

Eighth phase

Adds a finer 45° phase, an important building block for general algorithms.

t q[0];
06tdg1 qubit

Inverse T

Applies −45°, undoing a T gate when placed directly after it.

tdg q[0];
07rz(θ)1 qubit

Z rotation

Rotates phase by angle θ. It changes interference even when direct probabilities stay unchanged.

rz(pi/2) q[0];
08ry(θ)1 qubit

Y rotation

Rotates amplitudes by θ, directly changing the chance of measuring zero or one.

ry(pi/2) q[0];
09cx2 qubits

Controlled X

Flips the target only when the control is one. With H, it creates entanglement.

cx q[0],q[1];
10cu1(θ)2 qubits

Controlled phase

Adds phase θ only when both qubits are one. Common in Fourier-style circuits.

cu1(pi/2) q[0],q[1];
11swap2 qubits

Exchange

Trades the complete states of two qubits without measuring either one.

swap q[0],q[1];
12ccx3 qubits

Toffoli

Flips the target only when both controls are one, enabling reversible classical logic.

ccx q[0],q[1],q[2];
