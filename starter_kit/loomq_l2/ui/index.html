02 · Quantum basics

Eight ideas take you
from vectors to circuits.

Start with linear algebra: a quantum circuit multiplies a complex vector by matrices. Measurement then returns a bit string at random, using the squared magnitudes of the vector coordinates as probabilities.

01 / VECTOR

A qubit is a vector

One qubit is represented by a length-2 complex vector called its state. |ψ⟩ is simply a name for that vector. The fixed vectors |0⟩=[1,0]ᵀ and |1⟩=[0,1]ᵀ form the computational basis: the two results a measurement can report.

|ψ⟩ = α|0⟩ + β|1⟩ = [α, β]ᵀ
02 / NUMBER

Amplitudes become probabilities

The complex numbers α and β are called amplitudes. They are not probabilities. Measuring 0 has probability |α|²; measuring 1 has probability |β|². A valid state has total probability one. A state with multiple nonzero amplitudes is called a superposition of those basis vectors.

|α|² + |β|² = 1
03 / MEMORY

More qubits mean more coordinates

Two qubits use a length-4 vector whose coordinates are named |00⟩, |01⟩, |10⟩, and |11⟩. Combining independent qubits uses the Kronecker product, written ⊗: multiply every coordinate of the first vector by every coordinate of the second. Each added qubit doubles the vector length.

[a,b]ᵀ ⊗ [c,d]ᵀ = [ac,ad,bc,bd]ᵀ
04 / PROGRAM

A gate is a matrix

A gate updates the state by matrix multiplication. Its matrix is unitary: U†U=I, where U† is the conjugate transpose. This preserves vector length, and applying U† undoes U. A circuit is the ordered program of these matrix operations.

|ψ′⟩ = U|ψ⟩
05 / COMBINE

Phase controls interference

A complex amplitude has a magnitude and an angle; the angle is its phase. Phase does not change that coordinate's probability by itself. Later gates can add coordinates: aligned amplitudes reinforce, while opposite amplitudes cancel. This is interference.

1/√2 + (−1/√2) = 0
06 / READ

Measurement chooses one result

Measurement randomly selects one computational-basis label, such as 00 or 11. The probability is the squared magnitude of that label's coordinate. It returns the selected label as an ordinary bit string; after that read, the state equals the selected basis vector.

coordinate a₁₁ → P(11) = |a₁₁|²
07 / REPEAT

One shot is one complete run

For one shot, the program creates fresh qubits in |0…0⟩, applies every gate in order, and measures once. N shots restart this whole process N times. “Counts” is the map from each returned bit string to how often it appeared.

counts = { "00": 503, "11": 521 }
08 / JOINT

Entanglement is non-factorability

A multi-qubit state is entangled when it cannot be written as a Kronecker product of separate single-qubit states. In the Bell state below, neither qubit has its own independent vector, so measuring one bit constrains the other.

|Φ⁺⟩ = (|00⟩ + |11⟩)/√2

The definitions in action

Calculate a Bell pair

A Bell pair is an entangled two-qubit state whose measured bits are perfectly correlated: this example returns only 00 or 11, each with probability 1/2. To calculate it, write labels in |q₁q₀⟩ order. H gives q₀ two amplitudes of 1/√2, and CX flips q₁ only in the coordinate where q₀=1.

  1. INITIALIZE|q₁q₀⟩ = |00⟩Both qubits start at 0
  2. APPLY H TO q₀(|00⟩+|01⟩)/√2Two nonzero coordinates
  3. APPLY CX(|00⟩+|11⟩)/√2Cannot factor into two vectors
  4. MEASUREP(00)=P(11)=1/2Only matching bits appear
One important convention

In result key “10”, the rightmost character is c[0]. LoomQ normalizes every backend to this little-endian convention.

03 · Official gate set

Twelve gates.
The complete vocabulary.

Hidden competition cases use this same whitelist. θ is a rotation angle measured in radians; “dg” means the inverse gate.

Single-qubitPhase and rotationControlled and multi-qubit
01h1 qubit

Hadamard

Creates or recombines equal quantum paths—the usual doorway into superposition.

h q[0];
02x1 qubit

Bit flip

Swaps |0⟩ and |1⟩. It is the quantum counterpart of classical NOT.

x q[0];
03s1 qubit

Quarter phase

Adds a 90° phase to |1⟩. Interference makes that hidden phase observable.

s q[0];
04sdg1 qubit

Inverse S

Applies the opposite −90° phase. “Dagger” means inverse.

sdg q[0];
05t1 qubit

Eighth phase

Adds a finer 45° phase, an important building block for general algorithms.

t q[0];
06tdg1 qubit

Inverse T

Applies −45°, undoing a T gate when placed directly after it.

tdg q[0];
07rz(θ)1 qubit

Z rotation

Rotates phase by angle θ. It changes interference even when direct probabilities stay unchanged.

rz(pi/2) q[0];
08ry(θ)1 qubit

Y rotation

Rotates amplitudes by θ, directly changing the chance of measuring zero or one.

ry(pi/2) q[0];
09cx2 qubits

Controlled X

Flips the target only when the control is one. With H, it creates entanglement.

cx q[0],q[1];
10cu1(θ)2 qubits

Controlled phase

Adds phase θ only when both qubits are one. Common in Fourier-style circuits.

cu1(pi/2) q[0],q[1];
11swap2 qubits

Exchange

Trades the complete states of two qubits without measuring either one.

swap q[0],q[1];
12ccx3 qubits

Toffoli

Flips the target only when both controls are one, enabling reversible classical logic.

ccx q[0],q[1],q[2];
